# samuelgaluh.github.io
Selamat datang di repositori web portofolio saya! Website ini dibuat menggunakan React.js dan menampilkan keterampilan, proyek, dan sertifikat yang saya miliki.

## Fitur
- Beranda : Pengenalan singkat tentang diri saya
- Tentang Saya : Informasi lebih detail tentang latar belakang, pendidikan, dan minat saya
- Keterampilan : Daftar keterampilan teknis yang saya kuasai
- Proyek : Showcase dari proyek-proyek yang telah saya kerjakan
- Sertifikat : Tampilan sertifikat yang telah saya peroleh
- Kontak : Informasi untuk menghubungi saya
## Teknologi yang Digunakan
- React.js
- Styled Components
- Framer Motion (untuk animasi)
- React Router
- React Icons
## Cara Menjalankan Proyek
1. Clone repositori ini
   git clone https://github.com/SamuelGaluh/web-porto.git
2. Masuk ke direktori proyek
   cd web-porto
3. Install dependensi
   npm install
5. Jalankan aplikasi dalam mode development
   npm start
6. Buka http://localhost:3000 untuk melihat aplikasi di browser
## Cara Deploy
### Menggunakan GitHub Pages
1. Install GitHub Pages package
   npm install --save-dev
   gh-pages
2. Tambahkan properti homepage di package.json
   "homepage " : " https://SamuelGaluh.github.io/web-porto "
3. Tambahkan script deployment di package.json
   " scripts " : {" predeploy " : " npm run build " ,
   " deploy " : " gh-pages -d build "
4. Deploy website
   npm run deploy
### Menggunakan Netlify atau Vercel
1. Buat akun di Netlify atau Vercel
2. Hubungkan dengan repositori GitHub Anda
3. Ikuti petunjuk deployment di platform yang dipilih
